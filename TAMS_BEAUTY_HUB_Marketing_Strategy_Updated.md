## **3.4 TikTok Best Practices**

- Hook viewers in the FIRST 2 seconds - start with action, not intro
- Use trending Nigerian audio and sounds every week
- Add captions/text overlays so content works on mute
- Post between 7-9am, 12-2pm, or 7-10pm (peak Nigerian student hours)
- Use hashtags: #NaigerianFashion #FUTAgirls #AkureFashion #NailsNigeria #ThriftNigeria #StudentStyle
- End every video with a clear CTA: 'Link in bio to order / DM to book'
- Reply to ALL comments within 2 hours to boost algorithm reach
- Aim for 3-5 videos per week minimum for algorithm momentum

**SECTION 4: YOUTUBE STRATEGY**

# **4.1 Why YouTube for Tams Beauty Hub?**

YouTube builds long-term brand authority and drives evergreen traffic. Unlike TikTok (trending, fast), YouTube content stays discoverable for months and years. A Nigerian student searching 'affordable nail art tutorial' or 'FUTA campus style guide' can discover Tams Beauty Hub long after the video is posted - continuously bringing in new leads on autopilot.

## **4.4 YouTube Best Practices**

- Upload ONE video per week on a consistent day (e.g. every Saturday)
- Create custom thumbnails with bold text, bright colors, and a clear face/product
- Write keyword-rich titles: 'Thrift Haul Nigeria 2026 | FUTA Campus Fashion Under ₦5,000'
- Include timestamps in descriptions for longer videos
- End every video with a verbal CTA: 'WhatsApp link in description to order'
- Create a channel trailer introducing the brand (under 60 seconds)
- Add end screens linking to the next/previous video to increase watch time
- Respond to all YouTube comments - this signals engagement to the algorithm

## **4.5 YouTube → WhatsApp Funnel**

YouTube is a top-of-funnel discovery tool. Every video should funnel viewers to WhatsApp for ordering:

| **Step**           | **Action**                                                              |
| ------------------ | ----------------------------------------------------------------------- |
| 1\. Video CTA      | Verbally say: 'WhatsApp link in the description to order or book nails' |
| 2\. Description    | First line of description = WhatsApp link with pre-filled message       |
| 3\. Pinned Comment | Pin a comment with the WhatsApp link and a call-to-action               |
| 4\. End Screen     | Link to best video + subscribe button                                   |
| 5\. Community Post | After video goes live, post in Community tab with WhatsApp link         |

**SECTION 6: n8n SOCIAL MEDIA AUTOMATION PLAN**

# **6.1 What is n8n?**

n8n is a free, open-source workflow automation tool that connects apps and automates repetitive tasks without writing code. For Tams Beauty Hub, n8n can save 5-10 hours per week by automating content scheduling, lead follow-ups, WhatsApp responses, and analytics reporting.

## **6.2 n8n Setup Requirements**

| **Requirement**       | **Detail**                                                              | **Cost**            |
| --------------------- | ----------------------------------------------------------------------- | ------------------- |
| n8n Instance          | Self-hosted on a cheap VPS (e.g. Render, Railway, Contabo) or n8n.cloud | Free / ~\$5/month   |
| WhatsApp Business API | Via Twilio or Meta's WhatsApp Cloud API                                 | Pay-as-you-go       |
| Make.com / Airtable   | Free tiers for content calendar database                                | Free                |
| Google Sheets         | Lead tracking & broadcast list management                               | Free                |
| Buffer / Later        | Instagram & TikTok scheduling (connected via n8n)                       | Free tier available |
| Gmail / Email         | Automated order confirmation emails (optional)                          | Free                |

## **6.3 Core Automation Workflows**

### **Workflow 1: WhatsApp Lead Auto-Response**

Trigger: A new message arrives on WhatsApp Business number.

| **Step** | **n8n Node**     | **Action**                                                    |
| -------- | ---------------- | ------------------------------------------------------------- |
| 1        | WhatsApp Trigger | New message received from unknown number                      |
| 2        | IF Node          | Check if message contains 'price', 'order', 'nails', 'thrift' |
| 3        | WhatsApp Send    | Send automated welcome message with product menu              |
| 4        | Google Sheets    | Log lead: name, number, timestamp, enquiry type               |
| 5        | Wait Node        | Wait 24 hours                                                 |
| 6        | IF Node          | Check if lead has been converted (column in Sheet)            |
| 7        | WhatsApp Send    | If not converted: send follow-up with offer                   |

### **Workflow 2: Content Calendar Auto-Poster**

Trigger: Daily at 8:00am, check the content calendar.

| **Step** | **n8n Node**             | **Action**                                                     |
| -------- | ------------------------ | -------------------------------------------------------------- |
| 1        | Schedule Trigger         | Runs daily at 8:00am                                           |
| 2        | Airtable / Google Sheets | Fetch today's scheduled content (caption, image URL, platform) |
| 3        | IF Node                  | Check platform (Instagram / TikTok / WhatsApp)                 |
| 4a       | Buffer API Node          | Post to Instagram or schedule TikTok via Buffer                |
| 4b       | WhatsApp Send Node       | Send WhatsApp Status or Broadcast                              |
| 5        | Google Sheets Update     | Mark content as 'Posted' in the calendar                       |
| 6        | Gmail / Slack            | Send daily summary to owner: 'Today's posts went out ✅'       |

### **Workflow 3: New Follower Welcome DM (Instagram)**

Trigger: New follower detected on Instagram (via Meta API or Phantombuster).

| **Step** | **n8n Node**                | **Action**                                                                                       |
| -------- | --------------------------- | ------------------------------------------------------------------------------------------------ |
| 1        | Instagram Trigger / Webhook | New follower event                                                                               |
| 2        | HTTP Request                | Fetch follower username and profile                                                              |
| 3        | Instagram DM Node           | Send welcome DM: 'Hi \[name\]! Welcome to Tams Beauty Hub 💓 DM us to see our latest collection' |
| 4        | Google Sheets               | Log new follower with date                                                                       |
| 5        | Wait Node                   | Wait 48 hours                                                                                    |
| 6        | Instagram DM Node           | Send second message: 'Don't miss our new arrivals! Click here → \[WhatsApp link\]'               |

### **Workflow 4: Order Confirmation & Follow-Up**

Trigger: Owner marks an order as 'Confirmed' in Google Sheets.

| **Step** | **n8n Node**          | **Action**                                                                            |
| -------- | --------------------- | ------------------------------------------------------------------------------------- |
| 1        | Google Sheets Trigger | New row added with Status = 'Confirmed'                                               |
| 2        | WhatsApp Send         | Send customer: order confirmation + estimated pickup/delivery time                    |
| 3        | Google Sheets Update  | Mark 'Confirmation Sent' = Yes                                                        |
| 4        | Wait Node             | Wait 2 days after delivery date                                                       |
| 5        | WhatsApp Send         | Send: 'Hi \[name\]! How are you loving your \[item\]? We'd love a photo or review 💕' |
| 6        | Wait Node             | Wait 7 more days                                                                      |
| 7        | WhatsApp Send         | Send referral offer: 'Refer a friend and get ₦500 off your next order!'               |

### **Workflow 5: Weekly Analytics Report**

Trigger: Every Sunday at 9:00pm.

| **Step** | **n8n Node**               | **Action**                                         |
| -------- | -------------------------- | -------------------------------------------------- |
| 1        | Schedule Trigger           | Every Sunday 9pm                                   |
| 2        | Instagram API              | Fetch: follower count, post reach, engagement rate |
| 3        | TikTok API / Phantombuster | Fetch: video views, followers, profile visits      |
| 4        | Google Sheets              | Fetch: weekly orders, new leads, conversion rate   |
| 5        | n8n Code Node              | Build summary report (text format)                 |
| 6        | Gmail Send                 | Email weekly report to owner with key metrics      |
| 7        | Google Sheets Append       | Log weekly metrics to running analytics sheet      |

### **Workflow 6: Broadcast List Auto-Builder**

Trigger: New customer added to Google Sheets after a purchase.

| **Step** | **n8n Node**          | **Action**                                                                     |
| -------- | --------------------- | ------------------------------------------------------------------------------ |
| 1        | Google Sheets Trigger | New row: customer name, WhatsApp number, purchase date                         |
| 2        | IF Node               | Check if customer is already on broadcast list                                 |
| 3        | Google Sheets Update  | If new: mark 'Broadcast List = Yes', add to broadcast sheet                    |
| 4        | WhatsApp Send         | Send: 'You're now on our VIP list! Expect exclusive deals and early access 💅' |
| 5        | Airtable              | Tag customer as 'VIP' for segmented broadcasts                                 |
